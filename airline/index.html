✈ 국제선 출발 여객 대시보드

항공사별 국제선 출발 유임+환승여객
자료: 항공정보포털시스템(airportal.go.kr) 상세조회 · 시계열
최근 갱신월: –

1. 연도별 전체 여객 현황

연도 전체 합계 기준

2. 항공사 선택 (최대 8개, 검색 후 클릭하여 추가)

3. 월별 여객 추이

4. 전체 항공사 데이터 테이블

선택된 항공사만 표시 · 열 헤더 클릭시 정렬

5. 비교 대상 선택 (최대 3개 — 각 대상마다 연도별 라인을 1~12월 위에 겹쳐 표시)

개별 항공사 선택 (아래 목록에서 클릭, 최대 3개까지 위 대상들과 함께 선택 가능)

6. 연도별 월간 추이 비교

1월 ~ 12월, 연도별 겹쳐보기 · 대상을 여러 개 선택하면 나란히 비교 표시

7. 연도별 합계 비교

항공수송통계 기준: 국제선 출발+도착, 유임+환승여객 · 매월 airportal 게시 후 자동 갱신됩니다.
